★ Featured Patent
Automated Training-Set Collection for Natural Language to SQL Systems

Problem

Modern neural Text-to-SQL models achieve strong accuracy only when trained on large, high-quality (natural-language question, SQL query) pairs. But creating these pairs by hand is slow, expensive, and requires rare expertise in both SQL and the target database schema. As a result, publicly-available Text-to-SQL corpora are small, English-centric, and biased toward a narrow set of schemas — severely limiting the generalization of trained models to real-world enterprise databases.

Technical Approach

  1. Schema ingestion: the apparatus automatically parses the structure of a target relational database — tables, columns, primary/foreign keys, and data types — as the starting context for sample generation.
  2. Candidate SQL synthesis: using the schema, a generator enumerates syntactically valid SQL queries of increasing complexity (single-table selects, joins, aggregations, nested sub-queries), guided by the distribution of query templates observed in real workloads.
  3. Natural-language paraphrasing: each synthesized SQL query is paired with a natural-language question produced by a language model conditioned on the SQL and on schema metadata (column/table names and descriptions).
  4. Quality filtering: generated pairs are checked for consistency — the SQL is executed on a sample database, and the natural-language paraphrase is validated against the query's semantic graph, rejecting malformed or ambiguous examples.
  5. Active-learning loop: a downstream Text-to-SQL model is periodically re-trained, and cases where the model is uncertain are prioritized for additional human review or further synthesis — cheaply pushing training data toward the hard cases.

Key Claims

  1. An apparatus for collecting a training set for a natural-language-to-SQL translation system, comprising: a schema parser, an SQL candidate generator, a natural-language generator, and a quality validator.
  2. A method wherein candidate SQL queries are generated according to query-template statistics derived from a reference workload, ensuring that the synthesized training distribution matches real usage.
  3. The method further comprising validation by executing the generated SQL on a sample database and verifying that the generated natural-language question semantically corresponds to the query.
  4. The apparatus further comprising an active-learning module that selects additional training cases based on the predictive uncertainty of the downstream model.

Impact & Applications

This patent provides the data pipeline behind DSLAB's family of Text-to-SQL systems. By slashing the manual-labeling cost by orders of magnitude, it allows researchers and practitioners to train domain-specific NL-to-SQL models on arbitrary enterprise schemas — a critical enabler for conversational data interfaces, analytics copilots, and low-code BI tooling.
